# Roadmap

These are ideas, not promises or scheduled releases.

- Optionally import additional EXIF data, including GPS altitude, camera direction, and flash usage, without routinely fetching full-resolution originals. Analyze color palettes from low-resolution previews and explore creating an average image of a library or year.
- Add privacy-conscious place, region, route, and cluster statistics. Potential maps include an annual geographic center and separate day/night/twilight layers.
- Explore a population-density index using a locally supplied, versioned population grid. Show the source and year of the grid; do not send private coordinates to an external API by default.
- Improve the visual quality and presentation of downloads, especially the currently basic PDF and CSV reports.
- Add a distribution chart for the number of detected people per photo: one, two, three, four, and more.
- Create a visually appealing aperture chart, similar to the focal-length comparison.
- Better organize the dashboard, especially year-in-review highlights; explore optional weekly recaps.
- Explore a simple photo-book integration that places a page or two of selected year-in-review statistics beside the photos.
- Combine more filters across device, person, location, media type, album, and date range.
- Investigate scheduled syncs and deletion/change feeds if Immich exposes a reliable source for them.
- Add further UI languages and audit data-derived labels that are not yet keyed in the translation catalog.
- Consider photo challenges and transparent achievement badges without ranking photographic quality.
